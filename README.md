

# COIL-100 | Computer Vision

**Proyecto de visión por computadora basado en el conjunto de datos COIL-100 (Columbia Object Image Library).**

## Descripción

COIL-100 es un proyecto orientado al trabajo con imágenes de objetos y sus diferentes perspectivas, utilizando como referencia el conjunto de datos COIL-100 de la Universidad de Columbia.

El proyecto cuenta con una aplicación web desplegada para acceder a su propuesta y una implementación web independiente.

## Dataset: COIL-100

El conjunto de datos COIL-100 contiene:

- **7,200 imágenes** a color.
- **100 categorías de objetos** diferentes.
- **72 imágenes por objeto**.
- Resolución de imagen de **128 × 128 píxeles**.
- Rotación de 360° con incrementos de 5°.

Este conjunto permite trabajar con imágenes de un mismo objeto desde diferentes ángulos, siendo útil para experimentos de visión artificial, reconocimiento y clasificación de objetos.
